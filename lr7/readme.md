# Лабораторная работа №7
Цель работы: использование паттерна проектирования "Наблюдатель" для отслеживания изменений курсов валют через API Центробанка РФ.

Все также в качестве основы использовался класс из Лабораторной работы №5.
В качестве Наблюдателя - класс CurrencyObserver.
В качестве Слушателя выступает клиент, устанавливающий соединение с сервером.
