# Лабораторная работа №9
Цель работы: реализовать REST-сервис для просмотра текущего уровня бонусной программы, при этом:
- в качестве токена использовать JWT;
- код размещен и доступен в публичном репозитории на GitHub / GitLab;
- оформлена инструкция по запуску сервиса и взаимодействию с проектом;
- сервис реализован на __Flask__.

1. Ключ генерируется в отдельном файле (не токен доступа).
2. В файле [models.py](https://github.com/hbjnmcd/prog5/blob/main/lr9/models.py) дано описание модели: пользователи, пароли, уровни бонусной программы, количество трат.
3. В файле [app.py](https://github.com/hbjnmcd/prog5/blob/main/lr9/app.py) прописаны все существующие маршруты и запуск приложения.
4. В файле [tests.py](https://github.com/hbjnmcd/prog5/blob/main/lr9/tests.py) представлены все тесты, написанные для этого приложения.

## __ИНСТРУКЦИЯ ПО ЗАПУСКУ И ВЗАИМОДЕЙСТВИЮ С ПРОЕКТОМ__
1. Установить все зависимости, а также сгенерировать свой JWT_SECRET_KEY (можно использовать код, написанный в файле [generate_key.py](https://github.com/hbjnmcd/prog5/blob/main/lr9/generate_key.py)).
2. Запустить файл ```app.py```.
3. Теперь по разным адресам можно отправлять запросы, используя Postman или CURL или другой известный вам способ.
