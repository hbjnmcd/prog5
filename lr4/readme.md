# Лабораторная работа №4
Цель работы: Создание генератора с элементами ряда Фибоначчи

По итогу написанная программа просит сначала число, по которому будет выведено определенное количество элементов ряда Фибоначчи.
Затем, с использованием написанного класса, ```EvenNumbersIterator()``` выводит из предоставленного изначально в программе списка список, содержащий только те элементы, которые содержатся в ряде Фибоначчи.
